# 埋め込み HTML の使い方（記事を書く人向け）

microCMS の記事に、広告タグなどの HTML をそのまま入れる方法です。仕組みの説明は [article.md](article.md) の「埋め込み HTML」にあります。

## どんなときに使うか

リッチエディタ（本文）には `<script>` や `<iframe>` を貼れません。次のようなものは「埋め込み HTML」を使います。

- もしもアフィリエイトの「かんたんリンク」など、`<script>` を使う広告タグ
- `<iframe>` を使う広告・ウィジェット
- そのほか、リッチエディタでは作れない HTML

次のものは埋め込み HTML を使わなくてよいです。

| 入れたいもの | 使う方法 |
|---|---|
| ふつうのリンク（ASP のテキストリンクを含む） | 本文でそのままリンクにする（外部リンクは自動で別タブになる） |
| ASP のバナー画像・計測用の画像（`<img>` だけのタグ） | 本文に `［広告画像:画像のURL］` と書く（[article.md](article.md) の「広告の画像」） |
| YouTube などの動画 | まずはリッチエディタの埋め込み（oEmbed）を試す |

## 入れ方（3ステップ）

### 1. 記事の「埋め込み HTML」に追加する

1. microCMS で記事を開き、本文より下にある **「埋め込み HTML」** の「＋」を押して1つ追加する。
2. **名前** に、本文から呼ぶための名前を入れる（例: `証券口座`、`かんたんリンク1`）。
3. **HTML** に、ASP の管理画面でコピーしたタグを **そのまま** 貼る。

1つの記事にいくつでも追加できます。名前は記事の中で重ならないようにしてください。

### 2. 本文の出したい場所に印を書く

本文の、広告を出したい場所に、次の印を **1行（1段落）だけで** 書きます。

```
［埋め込み:証券口座］
```

- `［` `］` は **全角の角かっこ** です。`[ ]`（半角）・`【 】`・`「 」` では動きません。
- `:`（コロン）は **半角** です。全角の `：` では動きません。
- `埋め込み:` のあとに、1 で付けた名前をそのまま書きます。
- 同じ名前の印を何回書いてもかまいません（同じ広告を記事の上と下に出す、など）。

### 3. 公開して確認する

保存・公開すると、サイトが自動で作り直され、数分後に記事に反映されます。公開後の記事を開いて、広告が出ているか確かめてください。

- 印を書いた場所に、上に小さな「PR」のラベルが付いた広告が出れば成功です。
- 印の文字（`［埋め込み:…］`）は表示されません。

## 例

### もしもアフィリエイトのかんたんリンク

埋め込み HTML:

| 名前 | HTML |
|---|---|
| `かんたんリンク1` | ASP の画面で「コピー」したタグ全体（`<script>` から最後の `</script>` まで） |

本文:

```
おすすめの証券会社は次のとおりです。

［埋め込み:かんたんリンク1］

口座開設は無料で、スマホから申し込めます。
```

### 同じ記事に2つの広告

埋め込み HTML に `楽天証券` と `SBI証券` の2つを追加し、本文のそれぞれの場所に `［埋め込み:楽天証券］`・`［埋め込み:SBI証券］` と書きます。

## 表示のされ方

- **1行だけで書いた印**: 印の段落がまるごと広告に置き換わり、上に「PR」のラベルが付きます。ふつうはこちらを使ってください。
- **文の途中に書いた印**（例: `こちら［埋め込み:テキスト広告］から`）: その場所に HTML がそのまま入ります。「PR」のラベルは付きません。短いテキスト広告など、文中に入れたいときだけ使います。
- 広告の幅が画面より広いときは、広告の中だけ横にスクロールできるようになります（ページ全体ははみ出しません）。
- 記事の先頭には「本ページはプロモーション（広告）を含みます。」が自動で出ます。

## うまくいかないとき

| 症状 | よくある原因 |
|---|---|
| 何も表示されない（印も広告も消えている） | 印の名前と「埋め込み HTML」の名前が1文字でも違う（全角・半角、スペースの有無に注意）。または HTML が空 |
| 印の文字がそのまま表示される | `［］` が半角や別のかっこになっている、`:` が全角になっている、または印の一部だけ太字・色・リンクなどの装飾がかかっている |
| 「PR」のラベルが付かない | 印と同じ行（段落）にほかの文字がある、または印全体に太字などの装飾がかかっている。装飾のない印だけの行にする |
| 広告の枠は出るが中身が出ない | タグのコピー漏れ（最後の `</script>` がない など）。ASP の画面からもう一度コピーし直す。広告ブロッカーを入れたブラウザでは見えないこともある |
| 公開したのに変わらない | サイトの作り直しが終わっていない。数分待ってから、ブラウザを再読み込みする |

印を書く行は、装飾をすべて外した「ふつうの段落」にしてください。リッチエディタで別の文からコピーして貼ると、太字などが残ることがあります。困ったときは、印を一度消して手で打ち直すのが確実です。

## 注意

- **貼った HTML はそのままページに出ます。** サイト側では中身を確かめたり直したりしません。ASP など信頼できる提供元のタグだけを貼り、自分で書き換えないでください。タグの間違いで、ページの表示が崩れることもあります。
- **microCMS の画面では広告は見えません。** 本文には印の文字が見えるだけで、広告は公開したサイトでだけ表示されます。新しい広告を入れたときは、公開後に記事を開いて確認してください。
- 埋め込み HTML の中のリンクは、自動で別タブにはなりません（ASP のタグの指定のまま出ます）。
- 埋め込み HTML の中の画像は、本文の画像のような角丸・大きさの調整はされません。
- 広告は「PR」のラベルや記事先頭の表記で広告と分かるようにしています。広告であることを隠すような書き方（ラベルの出ない文中の印で目立つ広告を出す など）はしないでください（ステマ規制のため）。
- 使わなくなった埋め込み HTML は、本文の印と一緒に消してください。印だけ残っていても何も表示されませんが、サイトを作るときに注意が出ます。
